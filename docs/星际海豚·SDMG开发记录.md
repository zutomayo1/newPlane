# 星际海豚·S.D.M.G. 开发记录

## 2025-12-21

### 视觉与建模
- 引入镀铬流线机体、透明装甲与能量脊柱，整合六款涂装差异化光晕/拖尾。
- 新增矢量尾喷、量子传感阵列、厚重装甲板与巨型投影，提升机体压迫感。
- HUD 侧新增高效热区标记，帮助玩家把握 50%-90% 的火控区间。

### 战斗机制
- 过热系统延长至 3 秒冷却，并在高热区提供 30% 射速加成、加大散射惩罚。
- 触发过热时自动部署海星雷，并加入蒸汽粒子与“冷却 3 秒”提示。
- `ChlorophyteTracerBullet` 与 OverheatManager 现与射速逻辑联动，保证热量区段体验一致。

### 终极技能
- 轨道轰炸前加入声呐警告：触发 warning 音效、脉冲粒子与“声呐锁定”浮字。
- Orbital Strike 光束增加地面瞄准圈、逐帧 flicker 与余辉，整体更具威慑感。
