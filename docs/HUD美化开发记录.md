## 三、高质感文字系统

### 新增函数：draw_premium_text
位置：`utils/ui.py`

#### 支持4种渲染风格：

| 风格 | 效果 | 使用场景 |
|------|------|----------|
| `cyber` | 深色描边 + 底部微光线 | 标签文字 |
| `glow` | 多层渐变光晕 | 中等数值 |
| `metal` | 上亮下暗金属渐变 | 普通数值 |
| `neon` | 强烈霓虹外发光 | 高成就数值 |

#### 动态风格切换
- 得分/时间/统计数值根据阈值自动切换风格
- 普通状态 → `cyber`/`metal`
- 良好状态 → `glow`
- 优秀状态 → `neon`

## 四、性能优化

### draw_premium_text 缓存机制
```python
_premium_text_cache = {}
_premium_cache_max = 150
```

- 预渲染文字surface并缓存
- 相同文字+颜色+风格只渲染一次
- 超过150条自动清理旧缓存
- neon风格从~50次blit优化为1次

### draw_text 增强
- 添加 `outline` 参数支持描边效果
- 优化glow效果的渲染层数
