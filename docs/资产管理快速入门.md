# 🚀 资产管理系统 - 快速入门

本指南帮助你快速了解和使用新的资产管理系统。

## 📁 目录结构

```
newPlane/
├── assets/           # 资产文件（图像、音频）
│   ├── sprites/     # 精灵图
│   ├── audio/       # 音频文件
│   └── fonts/       # 字体文件
│
├── data/             # 配置数据（JSON）
│   ├── planes/      # 机体配置
│   ├── skins/       # 涂装配置
│   └── ui/          # UI配置
│
├── tools/            # 开发工具
│   ├── sprite_exporter.py    # 导出精灵
│   ├── audio_prebuild.py     # 预构建音频
│   └── config_migrator.py    # 迁移配置
│
└── utils/
    └── asset_manager.py      # 资产管理器
```

## 🔧 快速开始

### 1. 使用资产管理器

```python
from utils import asset_manager

# 获取精灵（优先从文件加载，不存在则返回None）
sprite = asset_manager.get_sprite("sprites/planes/striker/default.png")

# 获取机体配置
plane_config = asset_manager.get_plane_config("striker")
hp = plane_config.get("stats", {}).get("hp", 100)

# 获取颜色
cyan = asset_manager.get_color("primary_cyan")  # (0, 255, 255)

# 获取音效
sound = asset_manager.get_sound("explosion")
if sound:
    sound.play()
```

### 2. 混合模式（向后兼容）

在完全迁移之前，可以使用混合模式：

```python
def get_plane_surface(plane_id, visual):
    # 尝试从资产加载
    skin_id = visual.get("model_style", "default")
    sprite = asset_manager.get_sprite(f"sprites/planes/{plane_id}/{skin_id}.png")
    
    if sprite is not None:
        return sprite  # 使用资产文件
    
    # 回退到程序化渲染
    return _generate_plane_surf(plane_id, visual)
```

## ⚡ 迁移步骤

### 第一阶段：配置分离
1. 运行 `python tools/config_migrator.py` 选项4
2. 检查 `data/planes/` 下生成的JSON文件
3. 在代码中逐步替换硬编码引用

### 第二阶段：精灵导出
1. 运行 `python tools/sprite_exporter.py` 选项1
2. 检查 `assets/sprites/planes/` 下生成的PNG
3. 修改 `get_plane_surf` 添加文件加载优先

### 第三阶段：音频预构建
1. 运行 `python tools/audio_prebuild.py` 选项1
2. 音效会保存到 `assets/audio/sfx/`
3. 修改 `SoundManager` 优先加载文件

## ❓ 常见问题

### Q: 迁移后旧代码会失效吗？
A: 不会。系统设计为向后兼容，会自动回退到程序化生成。

### Q: 如何支持热重载？
A: 设置环境变量 `DEV_MODE=1`，资产管理器会跳过缓存。

### Q: 资产文件格式要求？
- 精灵：PNG（支持透明度）
- 音效：WAV 或 OGG
- 配置：UTF-8 编码的 JSON

### Q: 如何添加新涂装？
1. 在 `data/skins/{plane}_skins.json` 添加配置
2. 将精灵放到 `assets/sprites/planes/{plane}/{skin}.png`
3. 游戏会自动加载
