# 绯红恶魔·SCARLET 开发记录

## 基本信息
- **机体ID**: scarlet
- **全名**: 绯红恶魔·SCARLET
- **设计理念**: 东方幻想风高速截击机，融合《东方Project》蕾米莉亚·斯卡雷特的吸血鬼主题与Calamity Rogue职业的高机动性
- **开发日期**: 2025年12月20日

## 技能系统

### [F] 迷雾闪烁 (MistBlinkSkill)
- **效果**: 化作红雾瞬移至鼠标位置
- **特性**: 
  - 瞬移过程中完全无敌
  - 对穿过的敌人造成伤害
  - 冷却时间短，高机动性

### [G] 绯红不夜城 (ScarletMeisterSkill)
- **效果**: 东方弹幕风格高密度规则弹幕
- **特性**:
  - 多层同心圆弹幕花纹
  - 覆盖全屏的华丽弹幕
  - 伤害倍率 ×1.5

### [C] 命运之枪 (GungnirSpearSkill)
- **效果**: 投掷贯穿全屏的巨大红色光枪
- **特性**:
  - 参考北欧神话冈格尼尔
  - 贯穿所有敌人
  - 尽头处爆炸
  - 伤害倍率 ×4

### [E] 深红世界 (CrimsonWorldUltimate)
- **效果**: 时停领域展开，分身斩击全屏敌人
- **特性**:
  - 终极大招，需要通过造成伤害充能
  - 时间停止特效
  - 影分身斩击所有敌人
  - 伤害倍率 ×5
  - 左上角专属HUD显示充能进度

## 涂装系统 (6款皮肤)

### 1. scarlet_default - 绯红恶魔·猩红之枪
- **主题**: 标准吸血鬼形态
- **配色**: 猩红色机身 + 金色点缀 + 深红尾焰
- **特效**: 血红色光环、蝙蝠翼装甲

### 2. scarlet_remilia - 永夜女王·蕾米莉亚
- **主题**: 东方Project蕾米莉亚致敬
- **配色**: 深紫红色 + 粉红蝴蝶结 + 银色月光
- **特效**: 红月背景、蝙蝠群环绕

### 3. scarlet_flandre - 恶魔之妹·芙兰朵露
- **主题**: 芙兰朵露的破坏力主题
- **配色**: 鲜红色 + 彩虹水晶翼 + 金色装饰
- **特效**: 不稳定能量闪烁、棱镜折射光芒

### 4. scarlet_bloodmoon - 血月狂欢·午夜猎手
- **主题**: 血月之夜的狩猎者
- **配色**: 暗红色 + 银色月牙 + 血色光晕
- **特效**: 巨大血月背景、猩红雾气

### 5. scarlet_vampire - 不死魔王·德古拉
- **主题**: 经典吸血鬼德古拉伯爵
- **配色**: 纯黑色 + 深红披风 + 金色獠牙
- **特效**: 黑暗蝙蝠群、血红眼眸

### 6. scarlet_calamity - 灾厄血契·绯红瘟疫
- **主题**: Calamity Mod灾厄风格
- **配色**: 腐化红色 + 灾厄紫 + 毒绿点缀
- **特效**: 灾厄符文、血脉纹路、腐化粒子

## 视觉设计特点

### 核心元素
1. **魔枪形态**: 三叉戟造型机身，参考冈格尼尔神枪
2. **吸血鬼美学**: 蝙蝠翼、獠牙、血红眼眸
3. **水晶翅膀**: 多层次宝石翼展，折射光芒
4. **血之光环**: 动态血雾背景，压迫感十足
5. **残影系统**: 高速移动时的绯红残影轨迹

### 压迫感设计
- 参考了Yharon、Providence、Cthulhu等高质量机体的绘制手法
- 多层次光环叠加
- 动态粒子特效
- 细节丰富的机身纹路
