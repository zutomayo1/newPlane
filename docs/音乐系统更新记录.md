# 音乐系统更新记录（2025-12-21）

## 核心目标
- 为肉鸽循环提供可自适应的音乐叙事，让不同阶段、不同场景、Boss 警告都能有专属声场。
- 减少手动 `sound_mgr.play_music()` 的散落调用，统一由调度器管理淡入淡出、层叠与恢复。
- 为后续扩展（新增曲风、模块化房间、专属机体 BGM）预留接口。

## 关键改动
1. **MusicDirector 状态机**
   - 支持 `menu / explore / combat / boss / boss_challenge / victory / defeat` 等语义态，自动挑选最合适的 BGM。
   - `push_state`/`pop_state` 允许短暂覆盖（例如 Boss 战）后回到原轨；`pause_for_stinger` 可以在警告时停顿并播放提示音。
   - 层叠管理：根据强度动态叠加 `layer_pad`、`layer_pulse`、`layer_percussion` 等循环，形成更饱满的声场。

2. **AudioSynthesizer**
   - 额外生成三条循环素材，专供 MusicDirector 构建氛围/律动/鼓击层。
   - 所有新素材均缓存到临时目录，不影响包体。

3. **游戏流程接入**
   - `BackgroundManager` 根据 `element_type` 自动推算强度并切换对应曲风。
   - `main.py` 中的菜单切换、关卡重置、Boss 警告/生成/击败、Boss 挑战、胜负等节点均改为调度器驱动。
   - 新增辅助函数 `activate_background_music`、`deactivate_boss_music` 等，方便脚本调用。

4. **设置与音量**
   - `SoundManager` 支持音量观察者，MusicDirector 会在滑块调整时刷新所有层的音量，避免层叠音轨与主 BGM 音量不同步。

## 使用指引
- 切换某个状态：`music_director.set_state("combat", intensity=0.7)`。
- 短暂进入 Boss 音乐：`music_director.push_state("boss", intensity=1.0)`，结束后 `music_director.pop_state()`。
- 触发警告：`music_director.pause_for_stinger("warning", resume_state="combat", silence_ms=2000)`。
- 背景模块：调用 `activate_background_music(style_key)` 或直接 `BackgroundManager.resolve_bgm_intensity(element_type)` 取得建议强度。
- 自定义曲风：使用 `music_director.register_state("my_state", descriptor)` 添加描述，descriptor 结构可参考 `utils/audio.py` 内置示例。

## 后续思路
- 允许房间系统基于房间危机等级自动传入强度（例如：诅咒房 > 商店房）。
- 给特定机体（如 SDMG）配置专属 stinger/stem，进一步强化主题感。
- 将成就/剧情节点与 `victory/defeat` 状态串联，达成统一的音频叙事闭环。

## 状态矩阵与强度参考
| 状态 | 默认曲目 | 强度窗口 | 典型触发 | 建议层叠 |
| --- | --- | --- | --- | --- |
| `menu` | cinematic → calm | 0.2~0.4 | 主菜单/设置/涂装 | pad + 低强度 pulse |
| `explore` | normal / mystery / epic | 0.3~0.75 | 一般房间、地图漫游 | pad 常驻，pulse 按强度启用 |
| `combat` | intense / boss | 0.6~0.95 | 高危刷怪、精英波 | pulse 常驻，percussion ≥0.6 |
| `boss` | boss / funk / metal | 0.9~1.0 | Boss 战斗、本周目终局 | pulse + percussion 全开 |
| `boss_challenge` | orchestral_dark | 0.8~1.0 | Boss Rush 模式 | pulse + percussion，高强度 |
| `victory` | epic | 0.6 | 通关/大事件奖励 | pad 搭配高亮 stinger |
| `defeat` | ambient | 0.2 | 玩家阵亡、失败结算 | pad 单层，避免干扰 UI |

> 若想临时改变强度，可先通过 `music_director.set_state(state, intensity=0.9)` 再 push/pause，返回时会记忆之前的强度。

## 集成检查清单
1. **确定触发点**：先在逻辑中判定是否需要临时覆盖（Boss、警告、剧情）或恢复默认探索曲目。
2. **调用顺序**：若已有背景层，请先 `deactivate_boss_music()`，再 `set_state` 到新状态，避免重复 push。
3. **音量与设置**：在设置面板更新滑块后调用 `music_director.refresh_layers()`，确保层叠与主 BGM 音量对齐。
4. **资源引用**：自定义 descriptor 中的 `track` 必须存在于 `AudioSynthesizer.generate_all()` 输出；如需外部文件，可提前注入路径并缓存。
5. **线程/性能**：音乐调度全部在主线程调用，避免在耗时循环里频繁切换状态；可通过加锁或节流限制切换频率。

## 调试与故障排查
- **无声/播放失败**：确认 `pygame.mixer` 初始化成功；若日志提示权限或设备错误，可尝试降低采样率或关闭其他音频占用。
- **状态无法恢复**：检查是否多次 push 未 pop；可在调试时打印 `music_director.state_stack` 做栈平衡检查。
- **层叠音量异常**：调用 `sound_mgr.set_master_volume()` 后，注意 `_notify_volume_change()` 是否被改写；必要时手动 `music_director.refresh_layers()`。
- **警告停顿过长**：`pause_for_stinger` 的 `silence_ms` 支持动态调整，可根据 UI 反馈缩短至 1200ms 左右。

## 阶段性路线图
1. **V2（房间危机联动）**：RoomManager 根据房间稀有度传入 `intensity`，并在事件房间（商店/事件/Boss）切换特定状态。
2. **V3（机体主题化）**：允许机体在 `use_ultimate()` 或 SDMG 过热时触发自定义 stinger / layer；需要在 `Player` 中暴露 hook。
3. **V4（音序可视化）**：在 HUD 或背景特效中同步音乐节拍，例如脉冲光圈随 `layer_pulse` 变化，形成音画联动。
