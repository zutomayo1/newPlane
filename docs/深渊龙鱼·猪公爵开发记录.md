## 机体概述

- 深海蓝+龙鱼粉的标志配色
- 鲨龙卷留场控制系统
- 深渊泡折射机制
- 海啸滑翔变身形态

### 设计灵感
- 泰拉瑞亚 Duke Fishron Boss
- 深海风暴的狂暴力量
- 鲨鱼群与龙卷风的融合
- 海啸席卷的毁灭感

### 鲨龙卷系统 (Shark Tornado)

| 属性 | 数值 | 说明 |
|------|------|------|
| 生成方式 | 水矛命中 | 每次命中生成1个龙卷 |

| 吸扯范围 | 120像素 | 将敌人拉向龙卷中心 |
| 小鲨发射 | 每0.5秒 | 自动追踪最近敌人 |

| 掉落物 | 深渊泡（能量回复） |

- **类型**：远程穿刺投射物
- **特点**：1.3屏射程，命中生成鲨龙卷
- **伤害**：基础伤害 × 1.0
- **速度**：22
- **尺寸**：20 × 50 像素

```python
class AbyssSpear(pygame.sprite.Sprite):
    """深渊水矛 - 主武器，1.3屏射程，命中生成鲨龙卷"""
    
    def __init__(self, x, y, damage, owner=None, style="default", is_refract=False):
        self.max_range = HEIGHT * 1.3  # 1.3屏射程
        self.piercing = 1 if not is_refract else 2  # 折射泡可穿透
```

## 性能优化记录

### F技能优化
| 优化项 | 优化前 | 优化后 |
|--------|--------|--------|
| Surface尺寸 | WIDTH×HEIGHT | WIDTH×200 |
| 龙卷数量 | 7 | 5 |
| 粒子系统 | 多数组管理 | 单闪电简化 |
| 云层对象 | 8个独立 | 预计算相位 |
| 闪电 | 多道同时 | 单道大闪电 |

### G技能优化
| 优化项 | 优化前 | 优化后 |
|--------|--------|--------|
| 持续时间 | 4.5秒 | 3秒 |
| 气泡数量 | 25 | 12 |
| 能量环 | 3个+虚线 | 移除 |
| 漩涡臂 | 6条×8段 | 4条×6段 |

### 优化原则
1. 减少Surface尺寸
2. 减少粒子数量，增大单个粒子尺寸
3. 简化每帧计算量
4. 使用预计算替代实时计算

## 设计总结

**深渊龙鱼·猪公爵** 是一个以**留场控制**为核心的至尊机体：

### 核心循环
```
普攻命中 → 生成鲨龙卷 → 龙卷吸敌+小鲨弹
    ↓
深渊泡拾取 → 下次普攻折射分裂
    ↓
再次普攻(有龙卷时) → 引爆最老龙卷
    ↓
大招F/G/C → 强化龙卷群/泡风暴/海啸滑翔
```
