## 核心模块

### AssetManager (`utils/asset_manager.py`)

单例资产管理器，负责加载和缓存所有游戏资源。

```python
from utils.asset_manager import get_asset_manager

# 获取管理器实例
assets = get_asset_manager()

# 加载机体精灵
sprite = assets.get_plane_sprite("striker", "neon_blue")

# 获取机体配置
plane_config = assets.get_plane_config("striker")

# 获取Boss配置
boss_config = assets.get_boss_config("scarlet")
```

### 数据加载函数

```python
from utils.asset_manager import load_planes_dict, load_boss_db

# 加载所有机体配置 (保持原始顺序)
PLANES = load_planes_dict()

# 加载所有Boss配置
BOSS_DB = load_boss_db()
```

## JSON配置格式

### 机体配置 (`data/planes/{plane_id}.json`)

```json
{
  "id": "striker",
  "name": "突击者",
  "tier": 1,
  "base_hp": 100,
  "base_speed": 5,
  "base_fire_rate": 0.2,
  "base_damage": 10,
  "colors": {
    "body": [100, 150, 255],
    "accent": [255, 200, 100]
  },
  "skills": {
    "skill1": { ... },
    "skill2": { ... }
  }
}
```

### Boss配置 (`data/bosses/{boss_id}.json`)

```json
{
  "id": "scarlet",
  "name": "绯红恶魔·SCARLET",
  "tier": 3,
  "base_hp": 50000,
  "phases": 3,
  "attacks": ["laser_sweep", "bullet_hell"]
}
```

### 皮肤配置 (`data/skins/{plane_id}.json`)

```json
{
  "plane_id": "striker",
  "skins": {
    "default": { "name": "默认", "colors": {...} },
    "neon_blue": { "name": "霓虹蓝", "colors": {...} }
  }
}
```

### BGM预设 (`data/audio/bgm_manifest.json`)

```json
{
  "version": "1.0",
  "tracks": {
    "normal": {
      "file": "bgm_normal.wav",
      "bpm": 120,
      "roots": [110.0, 123.47, 146.83, 130.81],
      "mix": 0.50,
      "category": "explore"
    }
  }
}
```

## Fallback机制

所有数据加载都有硬编码fallback，确保即使JSON文件损坏/缺失游戏也能运行：

```python
# 尝试从JSON加载
planes = _load_planes_from_json()
if not planes:
    # 使用硬编码fallback
    planes = _FALLBACK_PLANES
```

## 开发工具使用


### 填充皮肤配置
```bash
python tools/skin_filler.py
```

## 性能优化

1. **PNG缓存**: 精灵图片预渲染为PNG，启动时一次性加载
2. **懒加载**: BGM按需生成，首次播放时合成
3. **后台预热**: 常用BGM在后台线程预生成
4. **配置合并**: fallback + JSON覆盖，减少IO操作

## 迁移指南

如需添加新机体/Boss：

1. 在 `config.py` 的 `_FALLBACK_PLANES` 添加fallback
2. 创建 `data/planes/{id}.json` 配置文件
3. 运行 `python tools/sprite_exporter.py` 生成精灵
4. 运行 `python tools/skin_filler.py` 生成皮肤配置
