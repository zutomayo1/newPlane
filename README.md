# 🚀 NewPlane - 2D弹幕射击游戏

一款融合肉鸽卡牌系统、多样化BGM和僚机编队的2D飞行射击游戏。

## ✨ 特性

### 🎮 核心玩法
- **16架特色飞机** - 每架飞机拥有独特的射击模式和大招
- **肉鸽卡牌系统** - 升级时选择卡牌强化你的战机
- **僚机编队系统** - 最多4架僚机协同作战
- **Boss挑战模式** - 多阶段Boss战斗,考验你的操作技巧

### 🎵 音频系统
- **26种BGM风格** - 涵盖Orchestra、Jazz、Piano、Rock、Electronic、Chiptune等
- **3D音效** - 基于位置的立体声效果
- **动态音乐** - 根据游戏状态(菜单/战斗/Boss)自动切换
- **优化音质** - 低通滤波、动态压缩、音量归一化

### 🎴 卡牌系统
- **基础卡牌** - 提升攻击、防御、速度等核心属性
- **修饰器卡牌** - 追踪模块、爆炸模块、穿透模块等特殊效果
- **协同效果** - 特定卡牌组合触发强力协同技能
- **可升级** - 每张卡牌最多升级3次

### 🎨 视觉效果
- **子弹涂装系统** - 多种子弹主题可选
- **粒子特效** - 爆炸、尾迹、击中反馈
- **赛博朋克风格** - 霓虹色调的未来科技美学
- **动态背景** - 17+种独特背景场景

### 🛠️ 游戏系统
- **武器系统** - 多种武器类型(激光、导弹、散射等)
- **成就系统** - 追踪你的游戏进度和成就
- **自定义系统** - 飞机涂装、子弹主题自定义
- **排行榜** - 记录最高分数

## 🎯 操作指南

### 基础操作
- **方向键/WASD** - 移动飞机
- **空格键** - 自动射击
- **1-4键** - 切换武器槽位
- **Shift** - 冲刺
- **Q键** - 主大招
- **G键** - 副大招
- **C键** - 第三大招

### 卡牌选择
- 升级时从3张卡牌中选择1张
- 卡牌可以叠加和升级
- 注意卡牌协同效果

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Pygame 2.0+

### 安装步骤

1. 克隆仓库
```bash
git clone https://github.com/zutomayo1/newPlane.git
cd newPlane
```

2. 安装依赖
```bash
pip install pygame
```

3. 运行游戏
```bash
python main.py
```

```

├── main.py              # 主程序入口

├── enemies.py           # 敌人类型定义
├── enemy_manager.py     # 敌人管理器
└── *.json               # 配置文件
```
