## 机体概述

**亵渎天神·普罗维登斯** 是一架以泰拉瑞亚灾厄模组亵渎天神为原型的终极机体，核心视觉元素为：
- 神圣几何形态，圣甲虫/盾牌造型
- 三对晶体盾翼可合拢形成茧壳
- 圣金 + 水晶粉的神圣配色

### 设计灵感
- **Terraria Calamity Mod** - Providence, the Profaned Goddess
- 神圣几何与晶体矿物美学
- 亵渎火焰与神圣光辉的双重属性
- 防御回血的独特生存机制

| 属性 | 数值 |
|------|------|
| 类型 | 滞留炸弹 |
| 伤害 | 基础伤害 × 1.5 (爆炸) |
| 机制 | 发射→悬停→延迟爆炸 |
| 爆炸半径 | 80像素 |
| 特性 | 范围伤害，距离衰减 |

```python
class HolyShardBullet(pygame.sprite.Sprite):
    """圣神爆碎 - 悬停后爆炸的神圣碎片"""
    def __init__(self, x, y, damage, angle=-90, owner=None, style="default"):
        self.hover_time = 30      # 悬停30帧
        self.explode_delay = 20   # 悬停后20帧爆炸
        self.explosion_radius = 80
```

**工作流程**：
1. 发射阶段：向上飞行至目标位置
2. 悬停阶段：原地悬停30帧，蓄能旋转
3. 爆炸阶段：延迟20帧后范围爆炸

## 茧化模式

### 固有能力：茧化模式 (cocoon_mode)

**触发条件**：机体静止不动超过1秒 (60帧)

| 效果 | 数值 |
|------|------|
| 生命恢复 | 3% 最大生命值/秒 |
| 视觉效果 | 盾翼合拢形成茧壳 |
| 治愈守卫 | 召唤4个守卫环绕 |
| 解除条件 | 任意移动 |

```python
# sprites.py - Providence 普攻逻辑
if (self.rect.x, self.rect.y) == self.last_pos:
    self.providence_stationary_timer += 1
    if self.providence_stationary_timer >= 60:  # 静止1秒触发
        self.cocoon_mode_active = True
        self.cocoon_shield = CocoonShield(self, style)
        for i in range(4):
            g = HealerGuardian(self, i, 4, style)
            self.cocoon_guardians.append(g)

# 茧化模式时恢复生命
if self.cocoon_mode_active:
    self.hp = min(self.max_hp, self.hp + self.max_hp * 0.03 / 60)
```

## 开发备注

### 设计亮点
1. **茧化模式**：首个拥有静止回血机制的机体
2. **滞留炸弹**：独特的悬停→爆炸攻击模式
3. **防御定位**：低速度换高生存能力
4. **三阶段技能**：每个大招都有完整的视觉演出

### 平衡性考量
- 低速度(3.2)配合茧化回血弥补机动性不足
- 滞留炸弹适合蹲点防守打法
- 亵渎之矛的高穿透提供输出保障
- 三个大招侧重不同：覆盖/扫射/爆发

### 战术建议
- 利用茧化模式在安全位置回血
- 预判敌人位置投放圣神爆碎
- 亵渎之矛用于清理直线敌群
- 被围时使用超新星爆发反击
