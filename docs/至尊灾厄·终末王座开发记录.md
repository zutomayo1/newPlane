# 至尊灾厄·终末王座 (SEPULCHER) 开发记录

## 机体概述
- **机体ID**: sepulcher
- **设计原型**: Terraria Calamity Mod - The Sepulcher
- **核心定位**: 灾厄召唤师，通过擦弹积累暴怒值激活强化状态

## 核心机制

### 暴怒系统 (Fury System)
- 擦弹积累暴怒值 (0-100)
- 满100时激活暴怒状态，持续5秒
- 暴怒状态下：射速+50%，额外发射2枚火弹

### 辅助系统
1. **骷髅尾巴 (SkullTail)** - 8节跟随尾巴，带火焰粒子
2. **灾厄力场 (CalamityAura)** - 机体周围能量场，响应暴怒值
3. **魔法阵光环 (MagicHalo)** - 机体上方旋转符文圈

## 大招技能

### F键 - 炼狱牢笼 (InfernalBoxSkill)
- **阶段1**: 四角火柱升起
- **阶段2**: 火墙形成封闭牢笼
- **阶段3**: 牢笼收缩，骷髅在内弹跳
- **阶段4**: 最终爆炸
- **阶段5**: 余烬消散

### G键 - 灾厄之雨 (RainOfCalamitySkill)
- **阶段1**: 天空裂隙开启，女巫剪影浮现
- **阶段2**: 硫磺火球雨倾泻
- **阶段3**: 女巫消散，燃烧区域持续

### C键 - 湮灭之眼 (EyeOfOblivionSkill)
- **阶段1**: 巨眼在屏幕上方形成
- **阶段2**: 眼睛缓慢睁开
- **阶段3**: 释放覆盖1/3屏幕的毁灭光束
- **阶段4**: 能量消散

## 攻击弹幕

### 硫磺火弹 (BrimstoneBolt)
- 主要攻击弹幕
- 带火焰尾迹
- 碰撞时产生爆炸效果

### 骷髅召唤物 (SepulcherSkull)
- 自动追踪敌人
- 保持距离发射火弹
- 生存5秒后消失

### 兄弟骷髅 (TheBrothersSkill)
- 两个骷髅绕机体旋转
- 自动攻击最近敌人
