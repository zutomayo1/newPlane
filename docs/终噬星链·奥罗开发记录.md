- 深紫+虚空蓝的标志配色
- 虚空链节生长系统
- 激光栅十字轰炸
- 黑洞终噬吞噬一切

### 设计灵感
- 泰拉瑞亚 Calamity Mod - Devourer of Gods (DoG)
- 宇宙巨蛇穿越维度的史诗感
- 虚空能量与时空裂隙
- 黑洞吞噬与衔尾蛇循环

## 核心机制

### 虚空链节系统 (Void Chain)
奥罗独特的链节生长攻击系统：

| 属性 | 数值 | 说明 |
|------|------|------|
| 生成方式 | 普通攻击 | 发射虚空链头 |
| 链节生长 | 每10帧 | 自动向前生长新节段 |
| 最大节数 | 5节 | 链节到达上限停止生长 |
| 存在时间 | 3秒 | 180帧后消失 |

### 链节特殊效果
| 效果 | 说明 |
|------|------|
| 链节伤害 | 每节独立造成伤害 |
| 激光栅 | 3节后开始发射十字激光 |
| 连锁爆炸 | 消失时依次爆炸 |
| 吞噬核掉落 | 击杀时概率掉落能量核 |

### 激光栅系统 (Laser Grid)
链节达到3节后自动释放激光：

| 属性 | 数值 |
|------|------|
| 触发条件 | 链节数≥3 |
| 发射间隔 | 60帧（1秒） |
| 激光范围 | 十字形，120px长 |
| 激光伤害 | 基础伤害 × 0.3 |

## 武器系统

### 主武器：虚空链弹 (VoidChainBullet)
- **类型**：生长型链式投射物
- **特点**：1.6屏射程，自动生长链节
- **伤害**：基础伤害 × 1.0
- **速度**：12
- **链头尺寸**：24px

```python
class VoidChainBullet(pygame.sprite.Sprite):
    """虚空链弹 - 主武器，自动生长链节"""
    
    def __init__(self, x, y, damage, angle=0, owner=None, style="default"):
        self.max_range = HEIGHT * 1.6  # 1.6屏射程
        self.chain_count = 0           # 当前链节数
        self.max_chain = 5             # 最大链节数
        self.grow_interval = 10        # 生长间隔（帧）
```

### 链节类 (ChainNode)
- **类型**：链式子弹节段
- **特点**：跟随前一节移动，3节后发射激光
- **伤害**：基础伤害 × 0.6
- **尺寸**：18px

```python
class ChainNode(pygame.sprite.Sprite):
    """链节 - 跟随链头，3节后发射激光栅"""
    
    def __init__(self, x, y, damage, parent, owner=None, style="default"):
        self.parent = parent           # 父节点（链头或上一节）
        self.chain_count = 0           # 当前是第几节
        self.laser_cooldown = 0        # 激光冷却
```

### 激光栅 (LaserGrid)
- **类型**：十字激光
- **特点**：高频伤害，穿透敌人
- **伤害**：基础伤害 × 0.3
- **范围**：120px × 120px

## 性能优化记录

### 优化历程

#### 问题1：技能期间严重卡顿
**原因**：每帧遍历所有敌人和子弹计算距离  
**解决**：降低遍历频率

| 操作 | 优化前 | 优化后 |
|------|--------|--------|
| 黑洞吸引 | 每帧 | 每3帧 |
| 持续伤害 | 每10帧 | 每15帧 |
| 裂痕伤害 | 每15帧 | 每30帧 |
| 网格伤害 | 每6帧 | 每12帧 |

#### 问题2：渲染复杂度过高
**原因**：漩涡臂绘制 6×20=120 次 circle 调用  
**解决**：简化渲染

| 效果 | 优化前 | 优化后 |
|------|--------|--------|
| 漩涡臂 | 6条×20段 | 4条×6段 |
| 引力环 | 5层 | 3层 |
| 黑洞核心 | 4层 | 2层 |
| 残影存储 | 30个 | 15个 |

#### 问题3：atan2三角函数开销
**原因**：每次计算角度使用 `math.atan2`  
**解决**：直接使用向量运算

```python
# 优化前
angle = math.atan2(dy, dx)
vx = math.cos(angle) * speed
vy = math.sin(angle) * speed

# 优化后
dist = math.hypot(dx, dy)
factor = speed / dist
vx = dx * factor
vy = dy * factor
```
