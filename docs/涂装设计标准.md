# 机体专属涂装设计标准

## 概述

本文档定义了游戏中机体专属涂装的设计规范，确保所有涂装具有高质量、独特性和一致性。

---

## 基础技术规范

### 渲染参数
```python
scale = 1.8           # 缩放比例
canvas_size = 120     # 画布尺寸 120x120
center = (60, 60)     # 中心点坐标
frame = 0-359         # 动画帧范围
pulse = math.sin(frame * 0.1) * 3  # 标准脉冲动画
```

### 文件结构
每个涂装模块必须包含：
```python
# 1. 涂装列表
XXXX_STYLES = ["xxxx_default", "xxxx_skin1", ...]  # 12种涂装

# 2. 判断函数
def is_xxxx_style(model_style):
    return model_style in XXXX_STYLES

# 3. 渲染入口
def render_xxxx_skin(surface, c, model_style, t, pid, static):
    ...

# 4. 绘制分发器
def draw_xxxx(surface, color, x, y, scale=1.0, skin_id="default", frame=0):
    ...

# 5. 各涂装独立绘制函数
def _draw_skin_name(surface, cx, cy, s, frame, pulse):
    ...
```

## 核心设计原则

### ❌ 禁止事项
1. **禁止换色涂装** - 不能只是改变颜色就作为新涂装
2. **禁止复制粘贴** - 不能复用其他涂装的代码结构
3. **禁止简单几何** - 不能只用基础圆形/方形堆砌

### ✅ 必须遵守
1. **形态独特** - 每个涂装必须有完全不同的视觉外形
2. **主题丰富** - 每个涂装需要明确的主题概念
3. **细节充分** - 包含粒子效果、动画、光效等细节
4. **代码独立** - 每个涂装函数代码量 50-80 行

### 主题来源参考

| 类别 | 示例 |
|-----|------|
| 神话传说 | 希腊神话(Ra, 赫菲斯托斯)、北欧神话(奥丁)、东方神话(龙、凤凰) |
| 自然现象 | 极光、风暴、火山、冰川、星云、黑洞 |

涂装主题应与机体特性相关联：

```

Frostflare (冰冻激光) → 冰川、极光、雪花、永冻
Nova (轨道炮) → 电磁、雷电、空间站、机甲
Spectrum (彩虹散射) → 棱镜、彩虹、霓虹、蝴蝶
Darkstring (标记狙杀) → 暗影、琴弦、蛛网、死神
```

## 视觉效果规范

### 必须包含的效果类型

#### 1. 动态动画
```python
# 脉冲效果
pulse = math.sin(frame * 0.1) * 3

# 旋转效果
angle = frame * 速度

# 波动效果
wave = math.sin(frame * 0.08 + offset) * amplitude
```

#### 2. 透明度层次
```python
# 使用 SRCALPHA 创建透明表面
surf = pygame.Surface((size, size), pygame.SRCALPHA)
pygame.draw.circle(surf, (*color, alpha), center, radius)
surface.blit(surf, position)
```

#### 3. 粒子系统
```python
# 环绕粒子
for i in range(particle_count):
    angle = frame * speed + i * (360 / particle_count)
    px = cx + math.cos(math.radians(angle)) * radius
    py = cy + math.sin(math.radians(angle)) * radius
    pygame.draw.circle(surface, color, (int(px), int(py)), size)
```

#### 4. 光效/光环
```python
# 多层光环
for layer in range(3):
    r = base_radius + layer * spacing
    alpha = base_alpha - layer * decay
    surf = pygame.Surface((r*2+4, r*2+4), pygame.SRCALPHA)
    pygame.draw.circle(surf, (*glow_color, alpha), (r+2, r+2), r)
    surface.blit(surf, (cx-r-2, cy-r-2))
```

## 颜色规范

### 机体主题色定义
```python
# Helios - 太阳火焰
solar_orange = (255, 150, 50)
corona_gold = (255, 200, 100)
magma_red = (200, 80, 50)

# Frostflare - 冰霜极光
ice_blue = (150, 220, 255)
frost_white = (230, 245, 255)
aurora_cyan = (100, 255, 200)

# Nova - 电磁科技
electric_blue = (100, 180, 255)
plasma_white = (220, 240, 255)
tech_gray = (80, 100, 130)

# Spectrum - 彩虹光谱
使用 colorsys.hsv_to_rgb() 生成渐变色

# Darkstring - 暗影信标
shadow_black = (25, 20, 30)
beacon_red = (255, 50, 50)
string_gray = (80, 75, 90)
```

### 颜色使用原则
1. 每个涂装定义 3-5 个主色调
2. 避免使用纯黑 (0,0,0) 和纯白 (255,255,255)
3. 透明度范围通常在 30-200 之间
4. 动态颜色变化使用 sin/cos 函数

## 代码质量标准

### 函数长度
- 每个涂装绘制函数：50-80 行
- 复杂效果可拆分子函数

### 注释要求
```python
def _draw_skin_name(surface, cx, cy, s, frame, pulse):
    """涂装中文名 - 简短描述形态特点"""
    # 主要颜色定义
    primary_color = (r, g, b)
    
    # === 第一部分：背景效果 ===
    ...
    
    # === 第二部分：主体结构 ===
    ...
    
    # === 第三部分：细节装饰 ===
    ...
```

### 性能考虑
1. 避免在绘制函数中创建大量临时对象
2. `random.seed()` 固定随机数确保动画稳定
3. 复杂计算提前到循环外

## 涂装命名规范

### 格式
```

```

### 示例

### 命名原则
1. 全小写，下划线分隔
2. 英文名简洁有意义
3. 对应中文名需要有诗意/史诗感
