# 光之在解·VISCERATOR 开发记录

## 基本信息
- **机体名称**：光之在解·VISCERATOR
- **原型参考**：Calamity Mod - Photoviscerator（光子在解）
- **设计风格**：双推进器粒子加速器 + EXO科技 + 粉绿能量
- **开发日期**：2025年12月20日

---

## 设计理念

### 核心概念
VISCERATOR是一款以Calamity Mod的Photoviscerator为原型的高科技粒子加速器战机。采用标志性的粉色+绿色双色能量系统，代表EXO科技的极致造物。

### 形态设计
- **核心形态**：双引擎粒子加速器，H型对称结构
- **驾驶舱**：六边形能量核心舱，全息投影界面
- **引擎**：圆柱形EXO推进器，能量环带包裹
- **武装**：双聚焦透镜炮台，粒子束发射口
- **特效**：粉绿双色能量脉络，等离子尾焰
- **装甲**：多层金属板+散热格栅+铆钉细节

## 技能系统

### F技能 - 推进器反转
- **效果**：快速后退闪避
- **特点**：保留原有设计

### G技能 - 粒子风暴
- **类型**：范围AOE
- **机制**：
  - 3波粒子释放（间隔0.15秒）
  - 第1波：24发，半径120
  - 第2波：12发，半径80
  - 第3波：24发，半径100（反向）
  - 总计60发粒子弹
- **特效**：
  - 粉绿双色粒子交替
  - 中央能量核心爆发
  - 扩散环形波纹
  - 命中产生小型爆炸

### C技能 - 星流过载
- **效果**：能量过载状态
- **特点**：保留原有设计

### R技能 - 光子湮灭
- **类型**：终极技能
- **机制**：
  - 蓄力阶段：能量聚集效果
  - 释放48道十字激光（12组×4方向）
  - 激光带有拖尾效果
  - 中央产生多阶段爆炸
- **特效**：
  - 蓄力粒子向中心汇聚
  - 十字激光图案旋转展开
  - 爆炸分4阶段（闪光→冲击波→能量射线→余晖）
  - 命中产生十字火花

## 机体建模

### 多层精细建模（SCARLET/ZENITH级别）

#### 引擎吊舱 `_draw_engine_pod()`
- 4层装甲渐变（主色→暗色→边缘→高光）
- 能量环带（3环双色交替）
- 散热格栅（6条）
- 铆钉细节（8颗）
- 动态能量脉络

#### 中央核心 `_draw_central_core()`
- 六边形驾驶舱轮廓
- 连接臂（到两侧引擎）
- 能量管线
- 中央能量核心
- 全息投影界面

#### 聚焦透镜 `_draw_focusing_lens()`
- 八边形底座
- 3层透镜（外圈→中圈→核心）
- 高光点
- 瞄准激光预览

## 动态效果系统

### 威压背景层（SCARLET级别）
- **末世压迫感背景**：5层深紫黑虚空脉动
- **双色恐惧涟漪**：6环粉绿交织向外扩散
- **粒子流光晕**：7层脉动光环双色交替
- **次元裂隙**：6道闪电状能量撕裂空间
- **能量粒子云**：16个飘散的高能粒子
- **六芒星几何**：神圣压迫符文环
- **暗角效果**：四角暗化增强压迫感

### 能量效果层
- **能量光晕脉动**：中央+双引擎三处光晕
- **动态尾焰**：摆动火焰+火花粒子
- **透镜闪烁**：双透镜能量闪烁
- **能量环流动**：引擎内部环形能量
- **驾驶舱光效**：全息投影+内部光

### 顶层威压效果
- **威压光柱**：从双透镜射出的激光
- **恐惧之眼**：透镜闪烁+瞳孔效果
- **能量脉冲波**：从中心向外的威压波
- **能量粒子喷射**：从尾焰喷出的粒子流

### 充能效果（ult_charge > 50%）
- 充能光环扩散
- 能量粒子环绕

## 文件结构

```
utils/
├── planes/
│   └── skins_viscerator.py    # 机体涂装与建模（~850行）
└── bullets/
    └── viscerator_bullets.py  # 技能弹幕系统（~780行）
```

### skins_viscerator.py 结构
- `VISCERATOR_THEMES`：6款涂装定义
- `_draw_engine_pod()`：引擎吊舱绘制
- `_draw_central_core()`：中央核心绘制
- `_draw_focusing_lens()`：聚焦透镜绘制
- `_build_cache()`：静态缓存构建
- `_draw_dynamic_effects()`：动态效果层
- `_draw_top_effects()`：顶层效果层
- `draw_viscerator_plane()`：主绘制函数

### viscerator_bullets.py 结构
- `ParticleStormBullet`：粒子风暴子弹
- `ParticleStormCore`：粒子风暴核心爆发
- `ParticleHitEffect`：粒子命中效果
- `CrossLaserBullet`：十字激光弹
- `LaserHitSpark`：激光命中火花
- `PhotonAnnihilationEffect`：光子湮灭爆炸
- `AnnihilationChargeEffect`：蓄力效果

## 技术亮点

1. **静态缓存 + 动态叠加**：机体静态部分预渲染缓存，动态效果每帧绘制
2. **SCARLET级别威压系统**：完整的深渊压迫感视觉效果
3. **高差异化涂装**：6款涂装色调完全不同
4. **双色能量系统**：粉+绿标志性配色贯穿全机
5. **多层精细建模**：装甲渐变+能量脉络+细节铆钉
6. **高效技能设计**：避免帧率问题的优化弹幕系统
