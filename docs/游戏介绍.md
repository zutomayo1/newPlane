## 📖 游戏概述

《赛博弹幕》是一款融合了肉鸽（Roguelite）元素的垂直卷轴弹幕射击游戏。玩家将驾驶各具特色的战机，在波次制的战斗中对抗无尽的敌人和强大的Boss，通过收集升级卡牌打造独特的战斗风格。

### 🎯 核心特色

- **30+ 独特战机** - 从新手到终极，每架战机拥有独特技能和大招
- **深度Roguelite系统** - 卡牌升级、协同效果、元进度
- **动态难度调整** - 根据你的强度自适应挑战
- **丰富的定制系统** - 240+ 涂装主题，100+ 子弹特效
- **15+ Boss战** - 多阶段战斗，考验你的技术极限

## 🃏 卡牌升级系统

### 卡牌流派

游戏中的卡牌分为三大流派：

#### ⚔️ 弹幕流 (Barrage)
专注火力覆盖和爆发伤害

| 卡牌 | 效果 | 稀有度 |
|:---|:---|:---:|
| 线性弹道 | 发射直线高速弹幕 | ★ |
| 分裂射击 | 子弹击中后分裂成多发 | ★★ |
| 爆裂弹头 | 爆炸范围伤害 | ★★ |
| 极速射击 | 大幅提升射速 | ★★ |
| 散射炮 | 一次发射多发散弹 | ★★ |
| 弹跳弹 | 子弹碰壁反弹 | ★★★ |
| 集束炸弹 | 释放小型炸弹 | ★★★ |
| 弹幕风暴 | 持续释放环形弹幕 | ★★★★ |

#### 🎯 狙击流 (Sniper)
专注单体爆发和精准打击

| 卡牌 | 效果 | 稀有度 |
|:---|:---|:---:|
| 精准光束 | 单发高伤穿透光束 | ★★ |
| 超载射击 | 周期性发射超高威力子弹 | ★★★ |
| 弱点打击 | 命中弱点造成额外暴击 | ★★ |
| 破甲弹 | 无视护甲真实伤害 | ★★★ |
| 轨道炮 | 贯穿全屏的高速弹 | ★★★ |
| 刺客标记 | 标记敌人必定暴击 | ★★★ |
| 处决 | 对低血量敌人巨额伤害 | ★★★★ |
| 狙击专注 | 静止不动伤害提升 | ★★★★ |

#### 🛡️ 控制流 (Control)
专注场控和生存能力

| 卡牌 | 效果 | 稀有度 |
|:---|:---|:---:|
| 能量护盾 | 吸收伤害的护盾 | ★ |
| 引力场 | 减速并吸引敌人 | ★★ |
| 时间膨胀 | 减缓敌方弹幕速度 | ★★★ |
| 冰霜领域 | 冻结周围敌人 | ★★★ |
| 相位闪避 | 被击中时概率闪避 | ★★★★ |

### 卡牌升级

- 每张卡牌最高升级到 **Lv.5**
- 升级大幅增强卡牌效果
- 可为基础卡附加最多 **3张参数卡**

### 协同效果

收集特定组合的卡牌会触发协同效果：
- **弹幕大师** - 3张弹幕卡 → 全体射速+30%
- **狙击专精** - 3张狙击卡 → 暴击率+50%
- **坚不可摧** - 3张防御卡 → 伤害减免30%
