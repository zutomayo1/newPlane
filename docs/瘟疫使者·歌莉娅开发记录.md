## 技能系统

### 被动技能：瘟疫光环
- **效果**：移动时在身后留下病毒尘埃轨迹
- **实现**：每8帧生成一个 `PlagueDust` 粒子
- **伤害**：基础伤害的 10%
- **持续时间**：120帧（约2秒）

### 被动技能2：瘟疫爆发
- **效果**：每命中敌人10次，在敌人位置生成毒云
- **实现**：检测 `player.stats['hits'] % 10 == 0`
- **伤害**：基础伤害的 30%/tick
- **持续时间**：180帧（约3秒）

### 主武器：瘟疫导弹
- **类型**：PlagueMissileBullet
- **特性**：命中后留下毒云区域
- **发射模式**：双发平行射击

### 特殊移动：瘟疫冲刺（双击方向键）
- **触发方式**：双击左/右方向键（18帧窗口内）
- **检测机制**：按下→释放→按下（真正的双击检测）
- **冲刺距离**：120像素
- **特效**：沿路径生成3个毒云陷阱
- **无敌帧**：冲刺期间15帧无敌
- **冷却时间**：30帧

### F技能：地毯式轰炸 (CarpetBombingSkill)
- **效果**：召唤轰炸机群进行地毯式瘟疫轰炸
- **范围**：全屏横向覆盖

### G技能：瘟疫核弹 (PlagueNukeSkill)
- **效果**：投下巨型瘟疫核弹，造成大范围持续毒害
- **特性**：爆炸后留下持久污染区

### C技能：盖亚之死 (DeathOfGaiaSkill)
- **效果**：释放毁灭性的生化风暴
- **特性**：全屏瘟疫扩散

## 技术要点

### 双击检测机制
```python
# 状态变量
goliath_key_released = True      # 按键是否已释放
goliath_last_tap_key = None      # 上次按下的键
goliath_tap_timer = 0            # 双击计时器
goliath_double_tap_window = 18   # 双击窗口（帧）

# 检测流程
1. 检测按键按下
2. 检查是否在窗口期内且按键已释放过
3. 如果是同一个键 → 触发冲刺
4. 否则记录当前按键，重置计时器
5. 按键释放时设置 released = True
```

### 无敌帧实现
- `goliath_invincible` 状态变量
- 冲刺时设为15，每帧递减
- `main.py` 中检测该变量跳过伤害判定

## 设计理念

歌莉娅是一架重型生化轰炸机，设计灵感来源于：
- 柴油朋克美学的粗犷机械感
- 生化武器的恐怖氛围
- 二战轰炸机的厚重感

机体特点是持续的区域控制能力，通过毒云和瘟疫尘埃创造危险区域，适合喜欢控场打法的玩家。
