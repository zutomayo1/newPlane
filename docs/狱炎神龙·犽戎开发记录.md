## 机体概述

**狱炎神龙·犽戎** 是一架以泰拉瑞亚灾厄模组龙王犽戎为原型的终极机体，核心视觉元素为：
- 机械龙形态，威严的龙首与利爪
- 日耀橙红 + 丛林深绿的配色
- 炼狱边界浮游炮系统环绕机体

### 设计灵感
- **Terraria Calamity Mod** - Yharon, Dragon of Rebirth
- 丛林龙王的火焰与重生意象
- 日蚀火焰与炼狱烈焰的双重属性
- 边界力场的领域控制概念

## 视觉设计

### 配色方案
| 颜色名 | RGB值 | 用途 |
|--------|-------|------|
| 丛林深绿 | `(0, 100, 50)` | 主色调、龙鳞、装甲 |
| 熔岩橙 | `(255, 69, 0)` | 火焰、日耀喷流 |
| 耀斑红 | `(255, 0, 0)` | 核心、能量溢出 |
| 圣金色 | `(255, 215, 0)` | 装饰、边界炮 |
| 尾焰橙 | `(255, 140, 0)` | 拖尾、余烬 |

### 机体外形
- **龙首**：机械化的威严龙头，发光的双眼
- **龙翼**：展开的机械龙翼，边缘火焰效果
- **龙爪**：前伸的利爪，蓄能状态
- **炼狱浮游炮**：4个环绕的边界能量球

### 固有能力：炼狱边界 (border_field)
- 4个浮游炮环绕机体旋转
- 每10帧自动辅助开火
- 形成持续的领域压制

## 开发备注

### 设计亮点
1. **炼狱边界系统**：首个拥有持续环绕浮游炮的机体
2. **三阶段大招**：每个技能都有完整的准备→执行→收尾流程
3. **领域控制**：通过浮游炮和千兆核爆实现强力AOE
4. **视觉震撼**：龙形机体配合火焰特效，视觉冲击力强

### 平衡性考量
- 高伤害(38)配合中等射速(120ms)
- 浮游炮持续输出弥补移动时的DPS损失
- 三个大招各有定位：清屏/召唤/追踪
