- 月蚀天象的神秘感

## 武器系统

### 主武器：月虹激光 (MoonLaser)
- **类型**：贯穿型光束
- **特点**：无限穿透，命中敌人叠加蚀印
- **伤害**：基础伤害 × 1.0
- **速度**：25
- **尺寸**：24 × 48 像素

```python
class MoonLaser(pygame.sprite.Sprite):
    """月虹激光 - 贯穿全屏的月虹光束"""
    def __init__(self, x, y, damage, owner=None, bullet_theme=None):
        self.piercing = 999  # 无限穿透
        self.speed = 25
```

### 副武器：月眼 (MoonEye)
- **类型**：追踪型眼球弹
- **特点**：自动追踪最近敌人
- **伤害**：基础伤害 × 0.6
- **触发**：每3发激光生成1个月眼
- **生命周期**：4秒 (240帧)

```python
class MoonEye(pygame.sprite.Sprite):
    """月眼 - 追踪目标的月蚀巨眼"""
    def __init__(self, x, y, damage, owner=None, bullet_theme=None):
        self.speed = 3  # 追踪速度
        self.lifetime = 240  # 4秒
```

### 蚀印系统
- 激光命中敌人累加蚀印标记
- 5层蚀印触发「月蚀削弱」效果
- 被削弱的敌人：减速 + 受到增伤

## 三大招系统

### F键 - 月蚀降临 (EclipseDescent)

**三阶段大招，总持续时间10秒**

| 阶段 | 名称 | 持续时间 | 效果 |
|------|------|----------|------|
| 第一阶段 | 月虹解放 | 2秒 (120帧) | 全屏月虹光束扫射 + 吸收敌方弹幕转化护盾 |
| 第二阶段 | 星骸召唤 | 3秒 (180帧) | 召唤8条月能触手 + 吸盘攻击 + 末端眼球监视 |
| 第三阶段 | 月蚀降临 | 5秒 (300帧) | 巨眼从天降临 + 触手环绕 + 毁灭光柱 + 疯狂debuff |

```python
class EclipseDescent(pygame.sprite.Sprite):
    """月蚀降临 - 三段大招"""
    def __init__(self, owner):
        self.phase_duration = [120, 180, 300]  # 2秒、3秒、5秒
        self.damage = owner.damage * 2.5
```

### G键 - 深渊触手 (AbyssalTentacles)

**从屏幕四边伸出12条巨型触手**

- **触手数量**：每边3条，共12条
- **持续时间**：5秒 (300帧)
- **伤害倍率**：1.8倍
- **特殊效果**：
  - 触手自动寻找并抓取敌人
  - 被抓取敌人持续受伤 + 减速
  - 触手末端有巨大眼球监视

```python
class AbyssalTentacles(pygame.sprite.Sprite):
    """【深渊触手】G键第二大招"""
    def _init_tentacles(self):
        edges = [
            ('top', 0, 1),      # 从上边向下伸入
            ('bottom', 0, -1),  # 从下边向上伸入
            ('left', 1, 0),     # 从左边向右伸入
            ('right', -1, 0),   # 从右边向左伸入
        ]
```

### C键 - 疯狂领域 (MadnessAura)

**释放精神污染波动的范围技能**

- **持续时间**：6秒 (360帧)
- **伤害倍率**：2.0倍
- **机制**：
  - 以玩家为中心释放不断扩大的疯狂波动
  - 敌人在领域内持续掉"SAN值"（持续伤害）
  - SAN值归零的敌人会陷入混乱（攻击友军）
  - 全屏幻觉效果：非欧几何、扭曲的眼睛、浮动符文

```python
class MadnessAura(pygame.sprite.Sprite):
    """【疯狂领域】C键第三大招"""
    def __init__(self, owner):
        self.duration = 360  # 6秒
        self.damage = owner.damage * 2.0
```

### Bug修复记录

#### Bug 1：G技能触手方向错误
**问题**：触手从屏幕边缘向外移动，而不是向内
**原因**：方向向量设置反了
**修复**：
```python
# 修复前
edges = [
    ('top', 0, -1),   # 错误：向上移动
    ('bottom', 0, 1), # 错误：向下移动
]

# 修复后
edges = [
    ('top', 0, 1),    # 正确：向下伸入
    ('bottom', 0, -1),# 正确：向上伸入
]
```

#### Bug 2：子弹涂装不显示
**问题**：装备涂装后子弹外观不变
**原因**：`MoonLaser` 类没有读取 `bullet_theme` 参数
**修复**：
1. 添加 `bullet_theme` 参数到 `__init__`
2. 根据 `bullet_theme.get('color')` 设置颜色
3. 在 `sprites.py` 射击代码中传递涂装

#### Bug 3：默认涂装颜色为 None
**问题**：未装备涂装时，`BULLET_THEMES["default"]` 的 `color` 是 `None`
**原因**：`dict.get(key, default)` 在 key 存在但值为 None 时返回 None
**修复**：
```python
# 修复前
self.moon_blue = bullet_theme.get('color', (100, 150, 220))

# 修复后
if bullet_theme and bullet_theme.get('color'):
    self.moon_blue = bullet_theme.get('color') or (100, 150, 220)
```

#### Bug 4：未装备涂装时不自动使用专属涂装
**问题**：玩家没有手动装备涂装时，使用的是 default 而不是机体专属涂装
**修复**：在 `Player.__init__` 中添加自动查找免费专属涂装的逻辑
```python
# 如果没有装备涂装，查找该机体的免费专属涂装
if not equipped_bullet_id or equipped_bullet_id == "default":
    for theme_id, theme_data in BULLET_THEMES.items():
        if (theme_data.get('exclusive_plane') == plane_id and 
            theme_data.get('cost', 0) == 0 and
            theme_data.get('color')):
            equipped_bullet_id = theme_id
            break
```

#### Bug 5：子弹涂装预览不工作
**问题**：主菜单涂装界面无法预览克苏鲁子弹涂装
**原因**：`render_cthulhu_bullet` 没有注册到 `BULLET_RENDERERS`
**修复**：
```python
# utils/bullets/base.py
from .cthulhu_bullets import render_cthulhu_bullet

BULLET_RENDERERS = [
    # ...
    render_cthulhu_bullet,
]
```

#### Bug 6：子弹形状始终为长条
**问题**：不管用哪个涂装，发射的子弹都是长条形
**原因**：`_draw()` 方法没有读取 `effects` 列表
**修复**：重写 `_draw()` 方法，根据 `effects` 绘制不同形状

#### Bug 7：F大招持续时间太短
**问题**：三阶段大招感觉太快结束
**修复**：延长持续时间
```python
# 修复前
self.phase_duration = [90, 150, 240]  # 8秒总计

# 修复后
self.phase_duration = [120, 180, 300]  # 10秒总计
```
