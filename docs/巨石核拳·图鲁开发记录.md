## 机体概述

**巨石核拳·图鲁** 是一架以远古岩石巨人为主题的至尊机体，核心视觉元素为：
- 不规则的岩石身躯，带有熔岩裂纹
- 双腕发射的巨石拳头
- 背部4格巨石充能条
- 岩灰 + 核熔橙的配色方案

### 设计灵感
- 远古巨石战神形象
- 火山熔岩的炽热能量
- 重型格斗机甲的力量感
- 卸甲强化的变身机制

## 核心机制

### 巨石充能系统 (Rock Charge)
图鲁独特的充能机制，通过射击和击中敌人积累能量：

| 充能来源 | 充能量 | 说明 |
|---------|--------|------|
| 发射子弹 | +1.0 | 每发子弹发射时 |
| RockFist击中 | +0.5 | 主武器命中敌人 |
| RockDebris击中 | +0.2 | AOE碎片命中敌人 |

- **最大充能**：4格
- **满充触发**：按 X 键触发卸甲强化

### 卸甲强化模式 (Unarmor Mode)
当巨石充能满4格时，可触发5秒的强化状态：

| 效果 | 数值 | 说明 |
|------|------|------|
| 伤害提升 | ×1.5 | 所有伤害提升50% |
| 射速提升 | ×1.3 | 射击间隔缩短30% |
| 移速提升 | ×1.2 | 移动速度提升20% |
| 视觉特效 | - | 能量光环 + 裂纹爆发 |

## 武器系统

### 主武器：岩核飞拳 (RockFist)
- **类型**：穿透型投射物
- **特点**：穿透2次，命中后爆裂成岩块AOE
- **伤害**：基础伤害 × 1.0
- **速度**：12
- **尺寸**：32 × 32 像素

```python
class RockFist(pygame.sprite.Sprite):

    def __init__(self, x, y, damage, owner=None, bullet_theme=None):
        self.pierce_count = 2  # 穿透次数
        self.pierced_enemies = set()  # 已穿透的敌人
```

### 次级武器：岩块碎片 (RockDebris)
- **类型**：AOE爆裂产物
- **特点**：从主武器命中点向四周飞散
- **伤害**：基础伤害 × 0.3
- **数量**：每次命中产生4个
- **寿命**：30帧

## 性能优化记录

### 问题：C技能使用时卡顿

**原因分析**：
1. 每帧创建 `random.Random()` 对象（非常耗性能）
2. 每帧生成过多粒子（4个熔岩粒子 + 3个能量粒子）
3. 没有粒子数量限制

**优化方案**：
```python
# 1. 预生成随机种子
self._rock_seeds = [random.Random(i + 99) for i in range(6)]

# 2. 使用确定性计算替代random调用
rr = 6 + ((i + j * 3) % 3) - 1  # 替代 random.Random(i + j).randint(-1, 2)

# 3. 添加粒子数量限制
self.max_particles = 80

# 4. 减少粒子生成频率
if self.phase_timer % 2 == 0:  # 每2帧生成一个
    self._add_particle(...)
```

| RockShield | 100 |

## 开发过程与Bug修复

### Bug #1：充能条不显示充能

**问题描述**：子弹击中敌人时，机体上的充能条没有增加

**原因**：子弹的 `_charge_ult()` 方法只给大招充能，没有给 `rock_charge` 充能

**修复方案**：
```python
# RockFist 击中时
if hasattr(self.owner, 'rock_charge'):
    self.owner.rock_charge = min(4, self.owner.rock_charge + 0.5)

# RockDebris 击中时
if self.owner and hasattr(self.owner, 'rock_charge'):
    self.owner.rock_charge = min(4, self.owner.rock_charge + 0.2)
```

### Bug #2：F技能特效不够震撼

**问题描述**：F技能特效相比克苏鲁的大招不够震撼

**优化方案**：
1. 增加浮空岩石环绕（8块）
2. 增加地面裂纹扩散（10条）
3. 增加能量环层数（5层）
4. 发射时生成 RockImpactEffect 冲击波
5. 增加拳头数量（6→8）
6. 延长持续时间（2.5秒→3秒）

### Bug #3：C技能卡顿

**问题描述**：使用C技能时游戏明显卡顿

**修复方案**：见[性能优化记录](#性能优化记录)
